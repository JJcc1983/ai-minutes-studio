# 🎙️ AI Minutes Studio (AI議事録 ＆ 音声要約スタジオ)

音声ファイルや会議メモのテキストから、構造化された議事録やアクションアイテムを瞬時に自動生成するマルチモーダルWebアプリケーションです。  
最新の **Google Gemini API** を活用し、LLMの実務導入で重要となる**トークン消費量および概算APIコストのリアルタイム可視化**を実装しています。

---

## 📌 課題と開発背景

* **会議後の議事録作成負担**: 録音データを聞き返しながら文字起こし・論点整理を行う作業に多大な工数がかかっている。
* **LLM運用のコスト意識不足**: 生成AIを業務導入する際、「1回あたりいくらのコストがかかっているか」が見えにくく、PoCから実運用へスケールさせづらい。
* **ソリューション**: 音声・テキスト両対応の要約基盤に加え、1リクエストごとの入出力トークン数・概算費用を即座に把握できる仕組みを一体化しました。

---

## ✨ 主な機能

1. **音声議事録生成（マルチモーダル処理）**
   * 会議音声ファイル（MP3 / WAV / M4A 等）を直接アップロード可能
   * 文字起こしと同時に「重要決定事項」「次回アクション（担当者・期日候補）」「課題」を構造化出力
2. **テキスト即時要約**
   * 長文テキストや簡易メモからの要点整理・課題抽出
3. **コスト＆トークンモニタリング**
   * APIレスポンスメタデータから入出力トークン数を取得
   * 概算利用コスト（円換算）を処理ごとに算出して表示
4. **セッション履歴管理 ＆ ダウンロード**
   * 同一セッション内の処理履歴をアコーディオン形式で一覧表示
   * 生成された議事録・要約テキストを `.txt` 形式でワンクリックダウンロード

## 🛠️ 技術スタック

| カテゴリ | 採用技術 | 選定理由 |
| :--- | :--- | :--- |
| **フロントエンド / UI** | Streamlit | 高速なプロトタイピングと直感的なダッシュボードUIの構築 |
| **バックエンド / 言語** | Python 3.13 | 安定したスクリプティングと最新の型・並列処理対応 |
| **生成AI / LLM** | Google Gemini API (`google-genai` SDK) | 音声の直接処理が可能なマルチモーダル認識能力と高いコストパフォーマンス |
| **パッケージ管理** | uv | 決定論的で高速な依存関係解決と再現性の高い仮想環境構築 |
| **開発環境** | VS Code (debugpy) | ブレークポイントを用いた効率的なデバッグおよび動作検証 |

---

## 💡 こだわった設計・実装のポイント

* **公式最新SDKの採用**: レガシーな `google-generativeai` ではなく、最新の `google-genai` パッケージを採用し、将来のAPI仕様変更に対応。
* **業務利用を想定した例外設計**: APIキーの未設定検知、対応外拡張子のハンドリング、レスポンスのメタデータ取得エラー時のフォールバック処理を実装。
* **モダンなPythonツールチェーン**: 従来の `pip` + `requirements.txt` から、高速かつ一貫性を保証する `uv`（`pyproject.toml` / `uv.lock`）へ統一。

## 🚀 ローカル起動手順

### 1. リポジトリのクローン
```bash
git clone [https://github.com/JJcc1983/ai-minutes-studio.git](https://github.com/JJcc1983/ai-minutes-studio.git)
cd ai-minutes-studio

2. 環境変数の設定

Gemini APIキーを取得し、環境変数に設定します。

Windows (PowerShell):
$env:GEMINI_API_KEY="your_api_key_here"

3. アプリの起動 (uv を利用)
uv run streamlit run app.py
ブラウザで自動的に http://localhost:8501 が開きます。
